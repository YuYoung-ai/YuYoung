# Handover 변경 확인과 PDF 생성 당시 원본 비교

완료 후에도 Handover 수정은 기존 처리 이력에 반영한다. 업무의 완료 시각·담당자·상태를 유지하면서 별도의 원본 변경 확인 대상으로 표시한다.

## 변경 확인

상단의 **Handover 원본 변경 확인**은 조회 기간·상태와 관계없이 보관 목록의 확인 대상을 보여준다. 업무 상세에서 변경 항목의 이전·현재 값을 비교한 뒤 **변경 내용 확인**을 누른다. 이 버튼은 해당 접수의 최신 Handover를 다시 읽고, 화면에서 비교한 원본 버전과 같을 때만 확인 이력을 저장한다.

원본 조회 실패·원본 누락·동시 변경·버전 충돌 시 확인 처리하지 않는다. 사용자 열람과 접수 상태 변경은 별개다. 댓글 초안은 유지한다. 원본을 다시 수정하면 새 확인 대상이며, 마지막 확인 내용으로 완전히 되돌리면 남은 변경이 없어 확인 대상에서 빠진다.

이 기능 배포 후 들어온 변경부터 추적한다. 과거 수정 이력은 기존 변경 이력에서 확인하며, 오래된 수정 건을 일괄 확인 대상으로 만들지 않는다.

긴 값은 비교 카드에 앞 300자를 표시한다. 전체 원본은 처리 결과와 서버 감사 이력에 보존한다. 전체 값의 해시로 비교하므로 표시 범위 밖의 변경이나 원문 복원도 구별한다. PDF 정보·동기화 시각처럼 임상/처리 본문과 무관한 변화는 원본 변경 확인 건수를 늘리지 않는다.

## PDF 생성 시점 비교

새 PDF는 렌더링 전에 Google 원본을 확인하고, Drive 전송 전후에도 문서 관련 원본의 지문을 확인한다. 전송 중 원본이 바뀌면 현재 문서 파일은 사용자가 공유·다운로드할 수 있게 보존하고, 자동 저장은 최신 내용을 확인한 뒤 재생성하도록 안내한다. 저장되지 않은 새 Drive 파일만 기존 정리 경로에서 처리한다.

본문 관련 병원·처리일·S/N·구분·분류·유형·교체품·비용·처리 내용·결과·특이사항을 비교한다. 표준 양식은 실제 처리자도 포함하고, 간소화 양식은 제외한다. 출력되지 않는 NS 평가·노즐 재사용 항목 변경은 PDF 재생성 대상으로 삼지 않는다.

- **생성 당시와 Handover 항목 동일**: 최근 동기화 원본의 해당 항목이 생성 당시와 같다.
- **PDF 생성 이후 원본 변경 · 재생성 필요**: 문서 관련 원본 항목이 바뀌었다. 변경된 항목명을 표시한다.
- **기존 PDF · 생성 당시 원본 비교 정보 없음**: 배포 이전 PDF 또는 비교 정보가 없는 파일. 오래된 문서라고 추정하지 않는다.
- **연결된 Handover를 불러온 뒤 비교 가능**: 관련 원본이 상세 이력 페이지에 아직 없다. 일치로 표시하지 않는다.

이 비교는 생성 당시 Handover 항목의 지문과 최근 원본을 대조한다. PDF 작성 화면에서 수동 수정한 본문, 사진·서명의 실제 내용 대조는 포함하지 않는다. 화면에도 최근 동기화 기준과 사진·서명 제외를 표시한다.

생성 시 원본 확인이 실패해도 로컬 PDF 파일 생성·공유는 가능하다. 생성 후의 원본을 생성 당시 값으로 바꿔 저장하지 않으며, 자동 저장은 원본 확인 후 재생성하도록 안내한다. 응답 유실 재시도는 동일 파일과 원래 비교 정보를 재사용한다.

## 배포와 검증

GAS의 `handover_inspection_pdf_gas.gs`만 기존 프로젝트·웹앱에 갱신한다. 새 시트 열이나 별도 저장 폴더는 만들지 않는다. Deno는 `work-source-review.ts`와 변경 확인 API를 반영한다. 웹/SW는 v243이다.

검증은 `test/work-source-review.mjs`, `test/inspection-upload-gas.mjs`, `test/inspection-upload.mjs` 및 기존 원본 갱신·KV·PDF·인증·알림 회귀 검증으로 수행한다. Chrome 합성 데이터 화면에서 변경 전후 표시, 완료 상태·댓글 초안 유지, 확인 이후 PDF 경고 유지, 모바일 가로 넘침 없음을 확인한다. 운영 기록에 임의의 변경 내용을 쓰지 않는다.
