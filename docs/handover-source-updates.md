# Handover 원본 수정과 조회 필터

Handover를 현장 처리 이력의 기준으로 사용한다. 신규 접수 자동 연결과 기존 연결 이력의 갱신은 별개다. 기존 연결은 불변 기록 ID로 추적하고, 최신 원본 버전이 달라지면 같은 처리 이력 ID의 원본·처리 내용을 갱신한다. 변경 전 원본은 감사 로그와 시트 전달 이벤트에 보관한다. CS 접수 내용·예정 방문·담당자·댓글·보완 메모·완료 상태·완료 시각은 유지한다. 완료·보류·취소 접수의 연결된 원본도 수정 대상이다. 삭제 접수와 Flow 보존 이력은 제외한다.

원본의 병원명·처리일이 정정되어도 기존 접수 연결을 임의로 옮기지 않는다. 원본 병원·처리일은 처리 결과에 표시한다. KV sourceIndex는 기록 ID의 현재 병원명·관찰 시각을 보관하고, 이전 병원명 아래 원본을 제거하며 늦은 이전 원본 전달을 거부한다. sourcePending은 미처리 갱신만 추적한다. 버전이 같은 재전달은 이력·댓글을 중복 생성하지 않는다. 원본 내용이 과거 값으로 되돌아가면 새 관찰 시각에 따라 정정 이력을 남긴다.

상단 동기화 버튼은 인증된 work_handover_refresh로 GAS 원본을 한 번 확인한 후 KV 접수 변경분을 조회한다. 처음 접속·자동 초기화는 기존 KV 정책을 유지한다. 원본 확인 실패 시 동기화 실패로 표시하며 이전 데이터는 유지한다. 주기적 GAS 작업도 활성 접수의 병원·날짜 및 이미 연결된 기록 ID에 해당하는 행만 재검사한다. 시트의 병원명·처리일·기록 ID 열을 읽고 일치한 행의 본문만 읽는다. 모든 Handover 본문을 매번 전송하지 않는다. 중복 ID·연결 원본의 잘못된 처리일/구분은 오류로 처리한다.

조회 기간과 상태 선택:

- 방문일 기준 기간을 카드 위에서 오늘·이번 주·지난주·이번 달·전체 기간 중 선택한다. 기본은 이번 주다.
- 카드 네 개는 동일한 기간·검색·담당자 등 상세 조건을 사용한다. 전체 업무는 모든 상태, 진행 중은 접수·방문예정·처리중, 결과 확인 대기는 결과확인, 처리 완료는 완료다. 카드 선택은 목록 상태만 바꾸므로 다른 카드의 집계 기준은 유지된다.
- 보류·취소 등 개별/복수 상태는 상세 필터에서 선택한다. 상태 상세 선택 시 카드 상태를 해제하고, 카드 선택 시 상태 상세 선택만 해제한다. 기간·검색·기타 상세 조건은 유지한다.
- 전체 기간의 결과 확인 대기는 별도 알림으로 표시한다. 0건이면 숨긴다. 확인하기는 기간·검색·상세 조건을 초기화해 전체 기간·결과 확인 대기로 이동한다.
- 휴지통은 목록 관리 버튼으로 분리한다. 닫으면 직전 조회 기간으로 돌아간다. 휴지통의 카드 숫자는 휴지통 데이터에서 집계하며 전체 확인 대기 알림은 살아 있는 접수만 사용한다.
- 목록 위에 방문일 기준 기간·상태·검색·세부 조건·결과 건수를 표시한다. 필터를 클릭하면 상세를 닫고 목록을 표시한다. 댓글/접수 초안은 기존 브라우저 보존 정책을 따른다.

기간 버튼과 상태 카드는 같은 조회 함수를 사용하고 선택 상태를 표시한다. 중복된 목록 상태 드롭다운과 목록 아래 빠른 필터는 제거한다. 수정모드 저장·충돌 처리 기능은 변경하지 않는다.

Handover 갱신 서버는 기존 GAS 웹앱 및 Deno production에 배포되어 있다. work_handover_refresh POST는 업무 모듈 내부에서 조회 핸들러로 전달하므로 기존 Code.gs 라우팅과 호환된다. 이번 기간/상태 UI 변경은 Pages 및 SW v240으로 배포하고 기존 GAS·Deno 운영 버전을 유지한다. KV 초기화·시트 이전·새 권한 설정은 필요 없다.

검증: work-source-updates.mjs, work-source-refresh-gas.mjs, work-metric-filters.cjs 및 기존 업무 KV·대기열·원본 삭제/복원·인증 중계·PDF 첨부 테스트. 운영 확인은 더셀피부과의원 강남본점 2026-10-14의 원본과 결과 비교 및 필터 집계·목록 일치로 수행한다.
