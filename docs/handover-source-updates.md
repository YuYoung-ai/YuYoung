# Handover 원본 수정과 조회 필터

Handover를 현장 처리 이력의 기준으로 사용한다. 신규 접수 자동 연결과 기존 연결 이력의 갱신은 별개다. 기존 연결은 불변 기록 ID로 추적하고, 최신 원본 버전이 달라지면 같은 처리 이력 ID의 원본·처리 내용을 갱신한다. 변경 전 원본은 감사 로그와 시트 전달 이벤트에 보관한다. CS 접수 내용·예정 방문·담당자·댓글·보완 메모·완료 상태·완료 시각은 유지한다. 완료·보류·취소 접수의 연결된 원본도 수정 대상이다. 삭제 접수와 Flow 보존 이력은 제외한다.

원본의 병원명·처리일이 정정되어도 기존 접수 연결을 임의로 옮기지 않는다. 원본 병원·처리일은 처리 결과에 표시한다. KV sourceIndex는 기록 ID의 현재 병원명·관찰 시각을 보관하고, 이전 병원명 아래 원본을 제거하며 늦은 이전 원본 전달을 거부한다. sourcePending은 미처리 갱신만 추적한다. 버전이 같은 재전달은 이력·댓글을 중복 생성하지 않는다. 원본 내용이 과거 값으로 되돌아가면 새 관찰 시각에 따라 정정 이력을 남긴다.

상단 동기화 버튼은 인증된 work_handover_refresh로 GAS 원본을 한 번 확인한 후 KV 접수 변경분을 조회한다. 처음 접속·자동 초기화는 기존 KV 정책을 유지한다. 원본 확인 실패 시 동기화 실패로 표시하며 이전 데이터는 유지한다. 주기적 GAS 작업도 활성 접수의 병원·날짜 및 이미 연결된 기록 ID에 해당하는 행만 재검사한다. 시트의 병원명·처리일·기록 ID 열을 읽고 일치한 행의 본문만 읽는다. 모든 Handover 본문을 매번 전송하지 않는다. 중복 ID·연결 원본의 잘못된 처리일/구분은 오류로 처리한다.

상단 조회 카드:

- 전체 업무: 한국 시간 이번 주 월~일의 모든 상태, 휴지통 제외. 누르면 아래 이번주·모든 상태를 선택하고 검색·상세 필터를 초기화한다.
- 오늘 방문: 한국 시간 오늘의 모든 상태(취소 포함), 휴지통 제외. 누르면 아래 오늘 방문·모든 상태로 연결한다.
- 결과 확인: 전체 기간의 결과확인 상태, 휴지통 제외. 누르면 아래 전체·결과확인으로 연결하고 검색·상세 필터를 초기화한다.
- 처리 완료: 현재 기간·검색·상세 조건에서 완료 상태의 수. 상태 조건만 완료로 대체한다. 진행중/결과확인 상태 전용 빠른 필터는 전체로 전환한다. 이번주/오늘/이번달/휴지통 등 조회 범위는 유지한다.

아래 필터와 상단 카드는 같은 조회 함수를 사용하고 선택 상태를 표시한다. 수정모드 저장·충돌 처리 기능은 변경하지 않는다.

배포: 기존 GAS 프로젝트의 hospital_work_gas.gs와 hospital_work_kv_gas.gs를 교체하고 기존 웹앱을 새 버전으로 갱신한다. 다른 Code.gs 및 PDF 모듈은 유지한다. work_handover_refresh POST는 업무 모듈 내부에서 조회 핸들러로 전달하므로 기존 Code.gs 라우팅과 호환된다. Deno는 새 main 빌드를 검증한 후 현재 고정된 production revision을 직접 갱신한다. KV 초기화·시트 이전·새 권한 설정은 필요 없다. Pages 및 SW v239를 적용한다.
