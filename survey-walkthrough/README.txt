본부장님 보고용 자료

1. 압축을 푼 뒤 01_고객만족도조사_영상보고.html을 Chrome 또는 Edge로 열어 주세요.
2. 상단 [전체 영상 보기]를 누르면 약 2분 6초 동안 전체 과정을 자동으로 보여줍니다.
   11번부터는 전체 화면에서 해당 항목을 확대하고 다시 축소합니다.
3. 직접 시연하려면 02_고객만족도조사_관리화면.html을 열어 주세요.
   로그인·비밀번호·설치·인터넷 연결이 필요하지 않습니다.
4. QR·안내 문자 → 병원 검색 → QR·링크 생성 → 고객만족도 조사 참여하기를 누르면 고객 설문도 시연할 수 있습니다.
5. 처음 상태로 돌아가려면 관리화면 상단 [처음 상태로]를 누르세요.

두 HTML 파일은 각각 이미지·영상·코드를 포함한 완성 파일입니다.
두 파일만 USB나 노트북에 복사해도 열립니다.
영상 보고와 관리화면은 상단 버튼으로 서로 이동할 수 있으므로 같은 폴더에 두세요.

병원명: 실제 큐어젯 입점병원 목록.
응답·점수·통계·전달 이력: 보고용 임시 데이터. 해당 병원의 실제 평가가 아닙니다.
문자 수신은 시연 예시이며 실제 발송하지 않았습니다.
관리화면에서 변경한 내용은 시연 화면에만 반영되고 새로 열면 초기화됩니다.
보고용 QR·링크는 실제 고객 배포용이 아닙니다.
