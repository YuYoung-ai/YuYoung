주간 병원별 장비 Label List

현장 처리 현황 시트에서 불러오거나 직접 입력 → 엑셀(.xlsx)·PPT(.pptx) 생성

문서 정보

① 현장 처리 현황 시트에서 불러오기

handover(현장 처리완료·공유)로 기록한 내용에서 병원명 · 장비 S/N · 장비 S/N 사진을 그대로 가져옵니다.
같은 병원+S/N이 여러 번 기록됐으면 가장 최근 1건만 남습니다. 불러온 뒤에도 표에서 자유롭게 수정할 수 있습니다.
기본값은 지난주 토요일 ~ 이번주 금요일(주간 보고 기준 1주)입니다. '장비 Label list' 시트에서 작성 유/무가 체크된 병원은 자동으로 빠집니다.
내려받으면 그 병원들의 작성 유/무가 체크되고 작성일자에 오늘 날짜가 적힙니다.

② 직접 입력 · 사진 일괄 배치

엑셀에서 병원명 → 장비 S/N → 비고 3개 열을 복사(Ctrl+C)해 아래에 붙여넣으세요.
한 줄에 한 병원, 열은 Tab(또는 쉼표)으로 구분됩니다. (비고를 비우면 '병원 장비'로 채워집니다)
휴대폰/카메라로 찍은 사진 여러 장을 한 번에 선택하면 표의 빈 사진 칸에 위→아래 순서로 채워집니다.
파일명 순서대로 정렬해 배치하므로, 병원 리스트 순서에 맞춰 이름을 붙여두면 그대로 들어갑니다.
개별 사진은 표의 사진 칸을 클릭하거나, 사진 파일을 칸 위로 끌어다 놓거나, 칸을 클릭한 뒤 Ctrl+V로 붙여넣어도 됩니다. 이미 사진이 있는 칸은 덮어쓰지 않습니다.
