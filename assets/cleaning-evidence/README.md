# 핸드피스 공정 변경 품질 검토 근거자료

`추정 교체비용 절감액` 카드의 산정 근거를 열람하기 위한 정적 보고서 이미지입니다.

- `handpiece-quality-review-01.png`: 품질 검토 결과 요약
- `handpiece-quality-review-02.png`: 화학적 세척 타당성 및 잔류성 검증
- `handpiece-quality-review-03.png`: 성능 및 기능 검증
- `handpiece-quality-review-04.png`: 경제성 및 효과성 분석

대시보드의 절감 단가는 기존 연간 비교분석 기준인 281,200원을 유지합니다. 근거자료에 기재된 281,208원을 100원 단위로 절사한 값입니다.

이 이미지는 서비스워커 프리캐시에 포함하지 않습니다. 절감액 처리 이력 또는 연간 비교분석의 근거자료를 열 때만 요청하고, 이후에는 기존 런타임 캐시 정책을 따릅니다.
