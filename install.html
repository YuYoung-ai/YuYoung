1

홈 화면에 앱 설치

사용하는 기기에 맞는 안내를 확인하세요.

  1. Chrome에서 이 페이지 열기카카오톡 안에서 열었다면 주소를 복사해 Chrome에서 여세요.
  2. 앱 설치아래 설치 버튼을 누르거나 Chrome 메뉴에서 ‘홈 화면에 추가’ 또는 ‘앱 설치’를 선택하세요.
  3. 홈 화면의 BAZ CS 실행앱에서 ‘앱 설치·알림 설정’을 열어 알림을 연결하세요.
  1. Safari에서 이 페이지 열기카카오톡 안에서 열었다면 주소를 복사해 Safari에서 여세요.
  2. 공유 → 홈 화면에 추가Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 선택하고 추가를 완료하세요.
  3. 홈 화면의 BAZ CS 실행앱에서 ‘앱 설치·알림 설정’을 여세요. 알림은 iOS 16.4 이상에서 지원합니다.
2

내 접수 알림 연결

로그인한 계정으로 이 기기를 연결합니다.

로그인 상태를 확인하고 있습니다…

담당자 지정 접수는 해당 담당자에게, 담당자 미지정 접수는 업무 사용자 전체에게 알립니다.

3

알림에서 바로 업무 확인

알림 선택 → 최신 접수·Handover 확인

알림을 확인한 시각을 기록하며, 업무의 처리 상태는 그대로 유지합니다. 받았던 알림은 업무 화면의 ‘알림’에서도 확인할 수 있습니다.
